How to use Light Studio

  1. Press Open Light Studio. A new library starts with a few demo photos, so you can try the controls straight away.
  2. Choose File → Import Photos to add JPEG, PNG, TIFF, WebP or supported RAW files from your device.
  3. Cull the shoot: rate photos with 0–5, flag picks with P, rejects with X and clear a flag with U, then group keepers into albums.
  4. Open a photo in Develop and set white balance first, then work through the Light sliders, Tone Curve, Color Mixer and Color Grading wheels.
  5. Press Y for a side-by-side before and after, or hold \ to peek at the original.
  6. Add local changes with a Brush, Linear or Radial Gradient, or a luminance or colour range mask, and finish with a crop and straighten.
  7. Export the finished photo as JPEG, PNG, TIFF or WebP. It arrives as a download.

Tips for better results

  • Back up after every session. File → Back Up Library downloads a zip of your catalog and imported originals (up to 4 GB), which File → Restore Library from Backup can read back.
  • Recover skies with Highlights. Pulling Highlights down restores detail in bright clouds; a negative Dehaze softens a scene instead of adding contrast.
  • Expect muted colour from some RAWs. DNG files use their own colour data. Other RAW formats currently start from a neutral or fitted profile, so check white balance and vibrance.
  • Know the RAW limits. CR3 and compressed Fujifilm or Olympus RAW files open only as their embedded preview, so edit a DNG or JPEG version for full quality.
  • Use presets as a starting point. Each built-in preset has an Amount slider, and you can paste or sync settings across a selection of similar shots.
  • Try black and white with V. The B&W Mix then lets you darken skies or brighten foliage channel by channel.
  • Search by field. Queries such as rating:>3 flag:pick narrow a large library quickly.

Where your photos are kept

Light Studio is meant for photographers who want a free, local alternative for culling and developing a shoot. Edits are non-destructive: the original file is never altered, and every slider change is stored as a setting that you can undo or reset.

Imported photos, thumbnails and the catalog are saved in this site’s private browser storage (the Origin Private File System, or IndexedDB where that is unavailable). Nothing is uploaded. The app asks the browser for persistent storage and shows a notice if it is not granted, which means the browser may clear the library when disk space runs low.

Light Studio questions

Which RAW formats are supported?

DNG, Canon CR2, Sony ARW, Nikon NEF, Fujifilm RAF (uncompressed), Panasonic RW2, Pentax PEF and uncompressed Olympus ORF.

Does Light Studio change my original photos?

No. Develop settings are stored separately from the image, and exporting creates a new file.

How do I move my library to another browser or computer?

Make a backup with File → Back Up Library, then open Light Studio in the other browser and choose File → Restore Library from Backup.
