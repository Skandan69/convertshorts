A few things to know.

Do these apps actually edit files?

Yes. Six studios open locally hosted ArtCraft browser engines. Video Studio opens the existing ConvertShorts editor. These are working editor entry points, not mock editor interfaces. The illustrations above are previews of the types of work you can create.

Do I need to upload my files or create an account?

No account is needed. Editing runs on your device. The first editor load downloads its engine files; optional model downloads depend on the upstream app. Imported file contents are not sent to a ConvertShorts processing server.

Is every desktop feature available in the browser?

Browser builds have their own file access, fonts, storage and export limits. Six apps have upstream web builds. FilmCraft is desktop-only: Video Studio uses ConvertShorts’ browser editor and also links to the full FilmCraft desktop release. Native CLI and MCP automation are not hosted by this website.

Will my work still be here tomorrow?

Save or export important work. Light Studio keeps a library in this browser and provides a backup command; clearing site data can remove it. Storage behavior differs across the other editors. There is no shared cloud project account or automatic transfer between studios.

What happened to the quick conversion tools?

They are still available. Use Convert Video, Image Tools, PDF Tools, Design Studio or QR Studio for a smaller, focused task.

Which browser should I use?

A current desktop Chrome or Edge browser is a practical starting point. WebAssembly and WebGL2 or WebGPU are needed for creative engines, and larger projects need sufficient memory. Tablets and phones may work, but full editor panels are easier to use on a desktop. Photo Studio includes a WebGL compatibility option.
