How to resize or compress an image

  1. Choose your image

    Select a JPG, PNG or WebP file from your device, or drop it into the image area. The preview shows your image before export.

  2. Set dimensions and framing

    Enter a width and height in pixels or choose a size preset. Keep original proportions to avoid changing the aspect ratio. Choose Fit whole image to keep every edge, or Crop to fill to remove the excess.

  3. Choose a format and file size

    Select JPG, PNG or WebP. For JPG and WebP, adjust quality or enter a maximum file size in KB. Export the image, check the reported size, and download the result.

Resize pixels or reduce KB: what is the difference?

Pixel dimensions describe how wide and tall a picture is. File size describes the storage it uses, in KB or MB. An application form may require both, such as a particular width and a file under 100 KB. Start with the requested dimensions, then adjust compression. Changing only the width does not guarantee a particular file size.

For a 50 KB, 100 KB or 200 KB target, choose JPG or WebP and enter that number in Maximum file size. The tool reduces quality while keeping your selected dimensions. If it cannot reach the limit, reduce the dimensions and export again. Check the downloaded file against the receiving website’s requirements.

Frequently asked questions

Can I compress an image to exactly 100 KB?

You can set 100 KB as a maximum target for JPG or WebP. The result may be smaller, and some images cannot meet the limit at the chosen dimensions. The tool reports this so you can reduce dimensions or choose a larger target.

Can I resize an image without losing quality?

Reducing dimensions removes pixels, and JPG or lossy WebP compression can remove detail. Start from the original, keep proportions and inspect the result. Enlarging a small photo cannot create missing detail; this tool does not offer AI upscaling.

Can I keep a transparent background?

Yes. Select PNG or WebP and enable Transparent background. Existing transparency is preserved when supported by the export format. This setting does not automatically remove a solid background from a photograph.

Does it resize images in bulk?

This page edits one image at a time. Download your result before choosing the next file.

What image sizes are supported?

Output can be up to 4096 pixels per side, within the 16-megapixel canvas limit. Large source images still need enough device memory.

Are my images uploaded or saved online?

No. Image processing happens in your browser. No account is needed and no watermark is added. Download the result before leaving or reloading the page.
