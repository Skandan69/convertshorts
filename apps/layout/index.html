How to use Layout Studio

  1. Press Open Layout Studio and let the Designcraft engine load. To explore first, choose File → New → Sample Document to open a finished sample magazine and take it apart.
  2. For your own project, start a new document and set the page size, orientation, number of pages, facing pages and margins. Bleed can be set for each edge if the piece will be printed and trimmed.
  3. Draw text frames and use File › Place to bring in images or copy. Word (.docx), RTF and plain-text files can be placed, and long text can autoflow, adding pages and threaded frames until it all fits.
  4. Thread one text frame to the next so a story runs across columns and pages, then format it with paragraph and character styles rather than one-off settings.
  5. Add colours to the Swatches panel and apply text wrap to images so copy flows around them.
  6. Save the document, then choose File › Export PDF… or an image export. In the browser, saved and exported files download to your device.

Tips for better results

  • Build styles first. Set up body, heading and caption paragraph styles before you lay out pages. Changing a style later updates every paragraph that uses it.
  • Apply styles by name. Quick Apply (Ctrl+Enter, or Cmd+Return on a Mac) lets you type a style name instead of scrolling the Styles panel.
  • Watch for overset text. When a story does not fit its frames, the leftover text is flagged. Thread another frame or edit the copy before exporting, or the end of the story will be missing.
  • Use guides and the baseline grid. Margin, column and ruler guides, plus a baseline grid, keep text lines aligned across columns and facing pages.
  • Design with the bundled fonts. The browser build does not use the fonts installed on your computer. Missing fonts are highlighted on screen and listed by Preflight, and Type › Find/Replace Font swaps them throughout.
  • Run Preflight before print. It lists missing fonts and glyphs and other problems while they are still easy to fix.

Who Layout Studio is for

It is built for multi-page documents where text and images have to work together: newsletters, school magazines, brochures, menus, event programmes, annual reports and zines. The tools, panels and shortcuts follow InDesign's, so designers who already know that workflow can find their way quickly, and newcomers learn habits that carry over to professional software.

Paragraphs are set with a Knuth–Plass composer and dictionary hyphenation, which spaces justified text more evenly than simple line-by-line wrapping. Exported PDFs contain real, selectable text with embedded font subsets. Documents can also be exchanged with InDesign 2026 as IDML files.

Everything runs in your browser tab. Files you open or place are read from your device, and saved or exported files are downloaded straight back to it.

Can I open InDesign files?

IDML files exported from InDesign can be opened and exported. Native INDD files cannot be read, so save an IDML copy from InDesign first.

Is the PDF suitable for a commercial printer?

Exports support CMYK colour, bleed and crop marks. This is an early release, so ask your printer for their specification, run Preflight, and check a proof before ordering a full print run.
