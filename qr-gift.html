Before you print

Three things worth knowing

Size matters more than you think

A plain code needs about 2cm across on paper. A photo halftone needs nearer 3cm, because the pattern is busier and a camera has more to resolve. Smaller than that and guests will struggle at the venue.

Test the actual proof

Scan the printed card, not the file on screen. Ink spread, paper finish and lighting all change how a code reads. Matte paper scans better than gloss under venue lighting.

The link has to outlive the card

The address is baked into the pattern, so the code never expires — but the page it points at can. Use a link you control and will not delete, not a temporary share link.
