How to use Photo Studio

  1. Press Open Photo Studio. The engine downloads once, then runs inside this page.
  2. Choose File → Open to pick a PSD, PNG, JPEG, WebP or TIFF from your device, or File → New to start a blank canvas at the exact size you need, such as 1280 × 720 for a video thumbnail.
  3. Before retouching, duplicate the photo layer. Add tonal and colour changes through Layer → New Adjustment Layer (Levels, Curves, Hue/Saturation and others) so each change can be tweaked or hidden later.
  4. To edit only part of the image, make a selection with the Marquee, Lasso, Magic Wand or Quick Selection tool, then turn it into a layer mask and refine its edge with a soft brush.
  5. Add a headline with the Type tool, then open the Layer Style dialog and apply Stroke or Drop Shadow so the text stays readable over a busy background.
  6. Use File → Save As to download a layered copy you can reopen, and File → Export As to download a flat image with the format, quality and scale you choose.

Tips for better results

  • Work non-destructively. Adjustment layers, masks and layer styles can be edited, reordered or switched off at any time, while painting directly on the photo layer is only reversible through History.
  • Filter a smart object, not raw pixels. Convert a layer to a smart object first; blurs and sharpening applied to it stay editable, so you can change the amount later.
  • Preview filters through a selection. Filter dialogs preview live on the canvas and only inside the active selection, which makes it easy to judge strength before you apply.
  • Set the final size early. Choose the image and canvas size before building a layout. Enlarging pixel layers afterwards softens them; shape and type layers scale cleanly.
  • Use Quick Export for PNG. When you just need a transparent PNG of the current document, Quick Export as PNG skips the options dialog.
  • Try Compatibility mode if the canvas misbehaves. The Compatibility mode button in the top bar reloads the editor on WebGL instead of WebGPU. Save your work before using it.
  • Mind memory on big files. Use 8-bit documents for screen work. 16- and 32-bit documents are supported, but they need much more memory inside a browser tab.

What it is good for

Photo Studio suits YouTube and blog thumbnails, social media graphics, quick product-photo clean-ups with the Spot Healing and Clone Stamp tools, and opening a layered PSD someone sent you when you do not have Photoshop installed.

Files you open are read by the browser on your own device and are not sent to a server. Saving and exporting hand the finished file to your browser as a normal download. PhotoCraft is an early-alpha engine, so a complex PSD may not look identical to the original application; keep the source file until you have checked the result.

Photo Studio questions

Can it open and save Photoshop PSD files?

Yes. PSD and PSB files open with their layers, masks, type layers and layer styles, and you can save back to PSD. A re-saved file is rebuilt rather than copied byte for byte, so keep the original as a backup.

Do I need an account?

No. The editor opens without sign-in, and the images you work on stay in your browser.

Why does the page warn me when I try to leave?

Your open document lives in the tab until you save or export it, so the page asks before you navigate away and lose unsaved work.
