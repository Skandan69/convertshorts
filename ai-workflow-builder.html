How to use the Workflow Builder

  1. Select Open Workflow Builder. To begin from a ready-made plan, choose Templates and pick Cinematic image → video, Product showcase or Three-shot story. For an empty canvas, choose + New.
  2. Under Add a step, add the pieces you need: Prompt, Reference image, Generate image or Generate video. Give the workflow a name in the field at the top so it is easy to find later under Your workflows.
  3. Click any step to open Step settings. Write the prompt, or for a generation step choose the model, aspect ratio, resolution and, for video, the duration, generated audio and a negative prompt.
  4. Link steps by selecting a step's output port and then a matching input port: a prompt goes into Prompt, an image goes into Reference. Press Escape to cancel a connection you started. The Prompt source and Reference source dropdowns in Step settings do the same job without dragging.
  5. For a Reference image step, choose a picture from your library or use Upload image (PNG, JPEG, WebP or GIF).
  6. Select Review budget to see each step's model and price and the workflow total. Until generation launches, this review is where a run stops.
  7. Use Export ZIP to share or back up the plan, and Import ZIP to open one as a new workflow.

Tips for better workflows

  • Keep scene and movement prompts apart. Describe what the image shows in one Prompt step and how the camera or subject should move in another, as the templates do. Each part is then easy to adjust on its own.
  • Use the Guided prompt builder. It asks for subject, action, setting, visual style, lighting, camera and things to avoid, then joins your answers into one prompt when you select Use this prompt. It runs in the page and does not call an AI model.
  • Match the model to the inputs. FLUX Schnell does not take reference images. Choose Nano Banana 2 when an image step should follow a reference, and Nano Banana 2 Edit when you want to change an existing picture; Edit needs a connected reference.
  • Pick video-friendly frames. Video steps accept 1:1, 16:9 and 9:16 only. Generate the key image in the same ratio so the clip is not reframed.
  • Inspect the request. Open Request preview in a generation step to see exactly which prompt, ratio and settings it will send.
  • Branch with Duplicate. Duplicate a step to try a second style or camera move side by side; press Fit to see every step again. A workflow can hold up to 40 steps and 80 connections.

Who it helps, and the limits to know

The builder is useful for anyone who repeats the same creative sequence: a seller who shoots one product photo and needs a styled scene and a short clip from it, a social media editor planning three matching shots for a reel, or a team agreeing a storyboard before anyone spends credits. Because every step and connection is visible, a plan can be reviewed and reused rather than retyped.

The canvas checks your plan as you build. Each input accepts one connection, a step cannot feed itself, and any connection that would create a loop is refused, so a workflow always moves forward. Portable ZIPs hold up to 150 MB per file and 300 MB in total. An imported ZIP becomes a fresh copy with new identifiers; it never carries over paid jobs from someone else's run.

Can I plan workflows without buying credits?

Yes. Templates, editing, the prompt builder, budget review and ZIP export and import are free. Credits will only be needed to run generation steps once AI generation opens.

Why can I not connect two steps?

Ports only accept matching types, and each input takes one connection. Disconnect the existing link under Connections in Step settings, or check that the step's model accepts references.
