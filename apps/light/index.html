Light Studio: quick guide

  • Use File → Import Photos, or drop photos into the editor.
  • Select a photo and adjust light, color, crop or masks in Develop.
  • Export finished photos. Use File → Back Up Library to keep a copy of your library.

Your library uses this browser’s local storage. Use one tab at a time and back it up; clearing site data can remove imported photos. AI model downloads are optional and separate.

Click inside the editor to use its keyboard shortcuts. If it cannot start, try a current desktop browser or open it in a new tab.
