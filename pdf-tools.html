How to merge, split or organise PDF pages

  1. Add your PDF files

    Select one PDF or several PDFs. Each imported page appears in the page list. Add additional documents when you want to combine them.

  2. Choose and arrange pages

    Use the page checkboxes to choose what to export. Move pages earlier or later with the arrow buttons. Delete selected pages when you want to remove them from the working list.

  3. Export your document

    Choose One PDF to merge selected pages, or Separate PDFs for a ZIP containing one PDF per selected page. Keep the original page size or select A4, Letter or custom dimensions, then export and download.

Merge PDFs, extract pages or delete unwanted pages

Use one combined PDF for a report with attachments, a collection of notes, or documents that need a consistent reading order. The export follows the order of the selected pages in the list. You can combine selected pages from more than one document.

To extract a range, deselect all pages, tick the pages you need, and export them as one PDF. To split into individual pages, choose Separate PDFs and download the ZIP. Deleting pages changes this workspace; your original file on your device is unchanged.

Choose PDF compression with the right trade-offs

Standard export preserves text and vector content where supported, but it may not make an already optimised PDF smaller. Smaller image-based PDF renders each page as an image. Select 96 DPI for smaller output or 144 DPI for more detail, then adjust image quality.

Image-based compression can help with some large documents, but removes selectable text and interactive content. It can also make some PDFs larger. Compare the exported file size and readability before using it, and keep the original. There is no guaranteed percentage reduction or exact KB target.

Frequently asked questions

Can I merge PDF files for free without an account?

Yes. Add the files, arrange the pages, select One PDF and export. There is no account requirement or added watermark, and the PDF contents are processed locally.

How do I split a PDF into separate pages?

Select the pages, choose Separate PDFs and export. The download is a ZIP with one PDF for each selected page. For a multi-page extract, choose One PDF instead.

Can I reorder pages or remove a page?

Yes. Use the arrow controls to move a page earlier or later. Uncheck a page to leave it out of an export, or select it and use Delete selected to remove it from the working list.

Will compressed text remain searchable?

Standard export keeps existing text where supported. Image-based compression flattens pages, so text will no longer be selectable or searchable as text. This tool does not perform OCR.

Can I compress a PDF to 100 KB or 1 MB?

This tool does not offer an exact PDF file-size target. Try image-based compression at lower resolution and quality, then check the actual download size. Very small limits may make a document unreadable or be impossible to reach.

What PDF files can I use?

Each imported PDF may be up to 100 MB, subject to device memory. Password-protected PDFs and interactive forms are not supported. This is not a signature-preserving editor; keep originals of signed documents.
