Photo Studio: quick guide

  • Open an image from the File menu, or create a new document.
  • Use the toolbar and Layers panel to edit. Keep adjustments on separate layers.
  • Use File → Save or Export. Download your work before leaving.

The editor runs locally. Keep an exported copy of important projects; browser support and memory can affect large files.

Click inside the editor to use its keyboard shortcuts. If it cannot start, try a current desktop browser or open it in a new tab.
