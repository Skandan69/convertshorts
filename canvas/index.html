🎙 YouTube embeds and the microphone

Two things need this page to be served by a web address rather than opened from your hard drive: YouTube/Vimeo playback (they check where the page came from, and a file has no address — that’s the “Error 153”) and the microphone. Your own video and audio files, images, drawing and everything else work either way. To unlock both, run the start-canvas.bat file that sits next to this one — or do it by hand:

  1. Export your board first with ⤓ — the next step is treated as a different site, so it starts empty.
  2. Open a terminal in the folder holding this file and run python -m http.server 8000
  3. Visit http://localhost:8000/infinite-canvas.html and load your board back with ⤒

Your board — videos and all — saves itself in this browser as you work. Use ⤓ to export one portable .json file with the media packed inside, and ⤒ to load it back.
