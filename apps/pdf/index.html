How to use PDF Studio

  1. Press Open PDF Studio. The Pdfcraft engine starts inside this page, so give it a few seconds on the first visit.
  2. Choose your document from the editor's File menu. Click once inside the editor before using keyboard shortcuts so the keys reach it rather than this page.
  3. Find your way around with the page thumbnails, the Bookmarks panel or the find bar, which searches the whole document as you type.
  4. Open Organize pages to see every page as a grid. Select pages, then rotate, delete or move them, insert a blank page, or insert pages from another PDF.
  5. To merge several PDFs into one, use Combine files. To break one apart, use Split (every n pages, or before pages you pick) or Extract to copy selected pages into a new document.
  6. Changed your mind? Press Ctrl+Z (Cmd+Z on a Mac). The Edit menu names each step it will undo, such as rotating pages.
  7. Save a new copy, then open it in a second PDF viewer to confirm the pages, order and orientation before you send it.

Tips for better results

  • Search for any tool. Press Ctrl+K (Cmd+K on a Mac) to open the command palette and type what you want, such as "rotate" or "split", instead of hunting through menus.
  • Select ranges quickly. In Organize pages, click the first page and Shift-click the last to select a run of pages; Ctrl-click (Cmd-click) adds or removes single pages.
  • Split by a fixed count. Splitting every n pages works well for scans that hold several equal-length forms, such as a stack of two-page applications.
  • Let Combine build the outline. Each merged file gets its own bookmark, with its original bookmarks nested beneath it, so a combined report stays easy to navigate.
  • Check the All tools list. The catalogue shows every tool, and tools still in development are marked with the milestone that will ship them, so you can see what is ready today.
  • Look before you share. Document Properties shows the title, author and keywords (which you can edit), the fonts used and whether each is embedded, and the security settings.

What PDF Studio is good for

It suits the everyday paperwork jobs: putting scanned pages the right way up, removing blank or duplicate pages, pulling a single chapter out of a long manual, or joining a cover letter, a form and its attachments into one file. When pages are combined or extracted, links, form fields, layers and attachments are carried across rather than dropped.

Password-protected PDFs open once you enter the password. If the author restricted printing or copying, the editor tells you and respects those rules; entering the owner password lifts them. Edits to an encrypted file are saved encrypted.

This is an early release. Rearranging, merging and splitting pages are its strengths. Rewriting the existing text on a page and recognising text in scanned images are still limited, so use a dedicated tool for those jobs.

Is my PDF uploaded to a server?

No. The engine runs inside your browser tab, and the document you open is read and processed on your device. Nothing is sent to ConvertShorts for processing.

Can I combine PDFs and then reorder the pages?

Yes. Combine the files first, then open Organize pages on the result to move, rotate or delete pages before saving the final copy.

Why do my shortcuts not work?

The editor only receives key presses after you click inside it. If a shortcut still opens a browser feature instead, use the menus or the command palette.
